Sitio estático para la evaluación de calidad de Telegram aplicando el modelo FURPS, desarrollado para la asignatura de Ingeniería de Software II — Grupo B1, Universidad de La Guajira.

## 📌 Descripción

Este proyecto presenta una valoración de Telegram desde la perspectiva de calidad del software, analizando factores como:

- Funcionalidad
- Usabilidad
- Confiabilidad
- Rendimiento
- Soporte

La información se organiza en una interfaz visual que facilita la comprensión del análisis académico.

## 🎯 Objetivo

Mostrar de manera clara y estructurada la evaluación de Telegram como herramienta de comunicación digital, con base en la plantilla FURPS y criterios de valoración definidos en el curso.

## 🚀 Publicación en GitHub Pages

Sigue estos pasos para publicar el sitio:

1. Suba este repositorio a GitHub.
2. Asegúrese de que la rama principal sea `main`.
3. En el repositorio, vaya a **Settings** > **Pages**.
4. En **Build and deployment**, seleccione **Deploy from a branch**.
5. Elija la rama `main` y la carpeta `/ (root)`.
6. Guarde los cambios.

GitHub generará la URL pública del sitio en unos minutos.

> El archivo principal es `index.html` y no se requieren dependencias ni instalación adicional.

## 🌐 URL esperada

Una vez habilitado GitHub Pages, la publicación quedará algo como:
